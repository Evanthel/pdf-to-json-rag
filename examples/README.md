# Examples

This folder is for public-safe, user-facing examples.

It is intentionally separate from the larger local benchmark and from ignored raw PDF inputs in `pdf/`.

Use it for:

- `demo-profile` onboarding assets
- `create-demo-pdf` and self-contained quickstart references
- packaging and release-surface references such as `package-check` and `release-check`
- sample queries
- example JSON output shapes
- lightweight workflow references for first-time users

Do not use it for:

- private benchmark PDFs
- generated chunk/index artifacts
- local evaluation reports
